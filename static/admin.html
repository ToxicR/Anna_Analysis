私聊底部「新建会话」菜单配置
  1. 飞书开发者后台 → 应用 → 机器人 → 开启机器人自定义菜单（仅私聊有效，建议选「悬浮菜单」）。
  2. 添加菜单项：名称 新建会话，响应动作选 推送事件，事件 Key 填 new_session。
  3. 事件与回调 → 添加事件 application.bot.menu_v6（机器人自定义菜单事件）。
  4. 发布应用版本后，用户在私聊输入框上方点击即可清空上下文并新建会话。
